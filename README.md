# Apex Construct Website

A modern, responsive website for Apex Construct, a premium construction company.

## Project Structure

This project is built with React and Vite.

- `src/components`: Contains all React components (Navbar, Hero, Services, Projects, Contact, Footer).
- `public/images`: Contains the asset images.
- `src/index.css`: Global styles and variables.

## Getting Started

1. **Install dependencies** (if not already installed):
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## Customization

- To change the color scheme, edit the variables in `src/index.css`.
- To update content, modify the respective components in `src/components`.
